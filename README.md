# PulseScope

ECG / PPG 双通道网页串口采集台。独立静态网站，使用桌面版 Chrome 通过 Web Serial 连接 Arduino。

## 使用

1. 使用 HTTPS 网页或本机 localhost 打开，关闭其他占用串口的软件。
2. 点击连接设备，选择开发板；串口 115200 baud、8N1。
3. 约 13 秒后开始尝试输出质量门控心率；可切换原始/实时滤波波形。
4. 点击开始记录，结束后导出 CSV。刷新或关闭前务必导出。

协议：`AA BB PPG_H PPG_L ECG_H ECG_L`，每帧 6 字节；10 位 ADC，目标 500 Hz。Arduino 两通道依次 analogRead，并非严格同时采样。协议没有校验和、序号或硬件时间戳。

## 数据处理

- PPG：0.5–8 Hz Butterworth 带通。
- ECG 显示：0.5–40 Hz 带通 + 50 Hz 陷波（Q=30）。
- ECG 心搏检测：5–20 Hz 带通后的 80 ms 能量包络。
- 3 秒预热 + 10 秒滚动分析，每秒更新；双通道质量通过且相差 ≤5 bpm 才显示综合估计。
- 原始 ADC 和因果滤波值一起导出，演示模式明确标记为合成数据。

心率仅供研究，未经参考设备准确度验证。因果滤波具有群延迟，不能直接用于 PAT/PTT、血压特征、HRV 或临床 ECG 形态分析。质量检查不能排除异常心律。

## 隐私

程序不包含测量数据，也没有自动上传采集数据的接口。测量记录保存在当前页面内存，用户自行导出。页面使用 Google Fonts 字体；字体加载失败时使用系统字体。

## 部署

GitHub Pages 从 main 分支根目录发布，无需构建或安装依赖。修改静态文件并推送后可自动更新。

本地预览：`python3 -m http.server 8765 --bind 127.0.0.1`，随后打开 http://127.0.0.1:8765 。
