# PulseScope

ECG / PPG 双通道网页串口采集台。独立静态网站，使用桌面版 Chrome 通过 Web Serial 连接 Arduino。

当前版本：LAB / 03（`20261106-v3`）。

## 使用

1. 使用 HTTPS 网页或本机 localhost 打开，关闭其他占用串口的软件。
2. 点击连接设备，选择开发板；串口 115200 baud、8N1。
3. 约 13 秒后开始尝试输出质量门控心率；显示可选标准滤波、高阶滤波、双线对比和原始 ADC。
4. 点击开始记录，结束后导出 CSV。刷新或关闭前务必导出。

协议：`AA BB PPG_H PPG_L ECG_H ECG_L`，每帧 6 字节；10 位 ADC，目标 500 Hz。Arduino 两通道依次 analogRead，并非严格同时采样。协议没有校验和、序号或硬件时间戳。

## 数据处理

- 所有流式滤波器用首样本的恒定输入稳态初始化，避免启动时把原始 ADC 的直流偏置当成阶跃。清空或信号中断后，重新初始化全部状态。
- 标准显示：PPG 0.5–8 Hz Butterworth 带通；ECG 0.5–40 Hz 带通 + 50 Hz 陷波（Q=30），保持原有系数。
- 高阶显示：PPG 0.5–8 Hz、ECG 0.5–40.5 Hz，均为 `butter(4, band)` 加 50 Hz 陷波（Q=30）。每通道为 8 阶带通加 2 阶陷波；截止更陡，频率相关延迟也更大。
- 两套显示滤波始终同时运行，切换时不清空采集、记录或心率分析窗。双线对比中，绿色/蓝色为标准，橙色为高阶。
- ECG 心搏检测：5–20 Hz 带通后的 80 ms 能量包络。
- 心率始终使用标准滤波与原有质量判断；高阶支路仅用于波形显示对比。此次没有改变质量门限。
- 3 秒预热 + 10 秒滚动分析，每秒更新；双通道质量通过且相差 ≤5 bpm 才显示综合估计。
- ECG 或 PPG 在分析窗口内超过 1% 的原始样本接近 ADC 边界（≤2 或 ≥1021）时，拒绝综合心率并显示对应通道的触底／饱和提示；PPG 饱和时保留合格的 ECG 单通道心率。此工程保护不能识别所有未到 ADC 边界的模拟前端饱和。
- 绘图与完整采样分离：约 100 ms 显示缓冲，环形缓冲最多保留最近 30 秒供 5/10/20 秒画面使用；绘图压缩保留峰谷。纵轴遇到大幅度立即扩展，约 2.5 秒时间常数缓慢收缩。样本数值不因绘图而修改。
- 原始 ADC 和两套因果滤波值一起导出，演示模式明确标记为合成数据。

CSV 原有前 12 列的位置和含义保持兼容，`ppg_filtered_causal` / `ecg_filtered_causal` 始终代表标准支路。新增 `ppg_high_order_causal`、`ecg_high_order_causal`、`display_profile`、`signal_segment`、`algorithm_version`。显示选择不改变采样或导出的标准支路值。

显示的心率来自过去 10 秒窗口，不能当作运动停止瞬间的心率。运动前后应连续记录原始数据，按事件时间离线提取对应区间。

算法回归检查：`node --test tests/*.test.mjs`。仓库中的测试只包含合成数据，不包含受试者记录。LAB / 03 的 18 项测试通过；本地两份原始记录的 132 个共同更新时间与原版质量通过/拒绝结果一致。浏览器合成演示导出的 31,531 帧连续，包含两套滤波值，前 12 列兼容。以上是软件检查，尚未进行该版本的实时硬件和参考心率验证。

心率仅供研究，未经参考设备准确度验证。因果滤波具有群延迟，不能直接用于 PAT/PTT、血压特征、HRV 或临床 ECG 形态分析。质量检查不能排除异常心律。

## 隐私

程序不包含测量数据，也没有自动上传采集数据的接口。测量记录保存在当前页面内存，用户自行导出。页面使用 Google Fonts 字体；字体加载失败时使用系统字体。

## 部署

GitHub Pages 从 main 分支根目录发布，无需构建或安装依赖。修改静态文件并推送后可自动更新。

本地预览：`python3 -m http.server 8765 --bind 127.0.0.1`，随后打开 http://127.0.0.1:8765 。
